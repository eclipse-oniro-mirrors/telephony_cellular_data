# gtest/gmock 头文件模板代码不做 CFI 插桩（思路对齐 netmanager_enhanced 单测先例，
# 但收敛为一条前缀规则）：
# - 预编译 libgmock.a/libgtest.a 未插桩，测试侧头文件实例化代码被插桩后，其对
#   gmock 内部函数指针/虚函数的间接调用会因目标未注册 type id 而校验失败 SIGABRT；
# - 且 OHOS ThinLTO 链接期存在模板实例 stub 注册丢失（实测 gtest-matchers.h 的
#   AnythingMatcher 系 MatchAndExplainImpl 未进 __cfi_check 表，同型 EqMatcher 系
#   却在），逐头枚举无法收敛，故按 googletest 目录前缀整体豁免；
# - mock 方法本体（test/mock/，不在 googletest 目录）保持插桩注册，mock 类 vtable
#   正常注册，满足系统 so（libtel_cellular_data_api.z.so）反向虚调用的校验。
